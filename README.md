# داشبورد شخصی من

نسخه اولیه داشبورد فارسی، راست‌چین و واکنش‌گرا با HTML/CSS/JavaScript.

## انتشار در GitHub Pages
1. یک مخزن جدید در GitHub بسازید.
2. فایل `index.html` را در ریشه مخزن بارگذاری کنید.
3. از `Settings → Pages`، گزینه `Deploy from a branch` را انتخاب کنید.
4. شاخه `main` و پوشه `/(root)` را انتخاب و ذخیره کنید.
5. پس از انتشار، آدرس سایت در همان بخش نمایش داده می‌شود.

## محدودیت‌های نسخه اولیه
- گفت‌وگو هنوز به مدل هوش مصنوعی متصل نیست.
- انتخاب فایل فقط نام فایل را در مرورگر نمایش می‌دهد و محتوای آن را تحلیل نمی‌کند.
- وظایف و سوابق در `localStorage` همین مرورگر ذخیره می‌شوند؛ بین دستگاه‌ها همگام نیستند.
- این نسخه بک‌اند، ورود کاربر یا ذخیره‌سازی ابری ندارد.
